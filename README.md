# STACKED

A strategy card game: capture cards from the table with pairs and sums,
take the table at the end of the round, and race two bots to the score
you pick.

Play it at https://stackedthegame.com.

## Rules

The official rules are in RULES.md.

## Running it locally

Needs Node.js 22.

    npm install
    npm run dev      # play it on your computer
    npm test         # run the tests
    npm run build    # check and build it
